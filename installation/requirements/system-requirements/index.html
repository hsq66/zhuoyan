系统要求

系统要求

硬件要求

最低配置：

  • CPU: 2 核心
  • 内存: 4GB RAM
  • 硬盘: 20GB 可用空间
  • 网络: 稳定的互联网连接

推荐配置：

  • CPU: 4 核心或更高
  • 内存: 8GB RAM 或更高
  • 硬盘: 50GB SSD
  • 网络: 高速互联网连接

软件要求

操作系统：

  • Ubuntu 20.04 LTS 或更高版本
  • CentOS 7/8
  • Windows Server 2016 或更高版本
  • macOS 10.15 或更高版本

运行环境：

  • Node.js 16.x 或更高版本
  • Python 3.8 或更高版本
  • Docker 20.10 或更高版本（可选）

数据库：

  • MySQL 5.7 或更高版本
  • PostgreSQL 12 或更高版本
  • MongoDB 4.4 或更高版本

浏览器支持

  • Chrome 90+
  • Firefox 88+
  • Safari 14+
  • Edge 90+

网络要求

  • 开放端口：80, 443, 3000
  • 支持 WebSocket 连接
  • 允许访问外部 API（如需要）
